# Лендинг диагностики практики — Академия «Алтей»

Статический лендинг без серверных зависимостей. Подходит для Vercel и обычного shared-хостинга REG.RU.

## Изменить ссылку Telegram

Откройте `script.js` и замените значение `TELEGRAM_URL`. Сейчас используется бот из действующего референса Altei.

## Локальный запуск

```bash
npm install
npm run dev
```

## Vercel

Импортируйте GitHub-репозиторий. Framework Preset: `Other`, Build Command: пусто, Output Directory: `.`.

## REG.RU

Загрузите содержимое папки проекта в корневую папку сайта (`public_html`, `www` или каталог домена — зависит от тарифа). Главный файл `index.html` уже находится в корне. Node.js и сборка не требуются.

Перед публикацией замените заглушки в `legal.html` на утверждённые документы и проверьте название бренда «Алтей»/«Алетейя».
